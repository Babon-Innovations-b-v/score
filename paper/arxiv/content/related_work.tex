\section{Related work}\label{related-work}

Genie learns an interactive environment from video \citep{bruce2024genie}; WorldGen generates traversable worlds from text \citep{wang2025worldgen}; WorldAct and WorldSculpt recover separate objects from generated worlds or video \citep{hu2026worldact, niu2026worldsculpt}. SCORE ships no generated world: a world generator may enter only as an optional reference step (Section 3.6).

Holodeck places retrieved objects by solving language-model constraints \citep{yang2024holodeck}; SceneCraft and recursive code world models write scenes as programs and compare renders \citep{hu2024scenecraft, li2026rcwm}; WorldClaw and AutoUE use agents to assemble open worlds and game code \citep{guo2026worldclaw, yin2026autoue}. LEGO-Anything finds that coding agents start scenes weakly, regress while editing and judge their own geometry unreliably, and fixes this with tools rather than training \citep{li2026lego}. SCORE shares that stance and applies it to worlds that do not exist yet, built to a person's picks.

Infinigen and Infinigen Indoors generate worlds and rooms from procedural rules, with materials as their own generators \citep{raistrick2023infinigen, raistrick2024indoors}, and ProcFunc gives these generators an interface language models write with far fewer errors \citep{raistrick2026procfunc}. Keeping one style across generated assets is an open problem \citep{wu2026production, yang2026flowscene}; Hunyuan3D Studio fixes style at the picture \citep{lei2025hunyuanstudio}. SCORE removes surface from generated models altogether.
