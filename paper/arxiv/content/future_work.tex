\section{Future work}\label{future-work}

\begin{itemize}
\tightlist
\item
  Build the three further worlds: a stylised underwater world, a simulation world for robots, and a third-person fantasy world.
\item
  Add a game engine adapter for the OpenUSD scene, and write each object's mass and friction into it.
\item
  Make assets interactable, which robotics in particular needs.
\item
  Finish the animals and the drapes: fins that move, animal motion retargeted from a captured set whose licence has been checked, and a drape route that passes the silhouette check on every look and the creator's review.
\item
  Make the surface stage hold on world 1: parts split along finishes, read from close-ups without shadow, and each repainted model shown before and after to the creator.
\item
  Make the open picture model's close-ups pass the shape check more often, so that the closed model is needed less.
\item
  Wrap open solvers as stages for worlds at other scales, starting with orbital dynamics through REBOUND \citep{rein2012rebound}.
\item
  Evaluate SCORE on LEGO-Bench \citep{li2026lego}.
\end{itemize}
