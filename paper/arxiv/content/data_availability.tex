\section*{Data Availability}\label{data-availability}
\addcontentsline{toc}{section}{Data Availability}

The framework's code, the source of this paper, its PDF and its arXiv tree are public at https://github.com/Babon-Innovations-b-v/score under the MIT licence. The run records from which the paper's numbers are read are in the repository under \texttt{paper/evidence/}, and every number in the source carries a comment naming the file, commit or issue comment it is read from. Environment 1's outputs are not yet made and are marked as gaps. OpenCap's LabValidation data (Apache-2.0) is fetched from its own source when needed and is not redistributed here.
