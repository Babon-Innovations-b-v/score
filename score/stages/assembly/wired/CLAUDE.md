# score/stages/assembly/wired/

The assembly's make as the stage table runs it (`stages.ASSEMBLY`): `assembly.make_from_seed`, then `release` (a stage
left in a reference cycle collected, so screens.take can write over its asset) and `silence` (a voice on a person the
characters layer did not lay moved out of the unplaced sounds into a gap complete fails by name).

- **Only the table imports this package.** The assembly package itself (`__init__.py`, `fitting.py`, `sounds.py`) is
  hashed by the light, settle, screens, cast, motion and characters rows; a fix there makes their accepted outputs
  again. A fix that only the assembly row needs goes here, and `score moved` shows it moves `assembly` alone.
- **A gap moves a fault, never hides one.** Only a voice whose person is not laid moves; any other sound playing at
  nothing still fails the layers gate.
- `test_the_assembly_stands_with_what_it_has.py`: one test, both ways round each rule.
